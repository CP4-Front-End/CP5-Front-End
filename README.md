# Melodia – Plataforma Musical Interativa

## Descrição do Projeto
Este repositório contém o desenvolvimento do **Melodia**, um projeto acadêmico de front-end com proposta de uma plataforma musical interativa voltada para descoberta de artistas, playlists e experiências personalizadas para o usuário.

A ideia do projeto é unir **identidade visual moderna**, **navegação intuitiva** e **layout responsivo**, apresentando uma interface inspirada em plataformas de música, com áreas dedicadas a **artistas**, **playlists**, **conteúdos em alta**, **login** e **planos**.

O site foi desenvolvido com foco em **estrutura semântica**, **responsividade** e uso de classes utilitárias do **Tailwind CSS**, simulando a experiência de uma aplicação musical real.

## Objetivo
O principal objetivo deste projeto foi aplicar, na prática, conceitos de desenvolvimento front-end, incluindo:

- Estruturação de páginas com **HTML5**
- Estilização com **CSS3**
- Uso de **Tailwind CSS**
- Criação de layout **responsivo**
- Navegação entre páginas
- Organização visual de conteúdos musicais
- Publicação do projeto com **GitHub Pages**

---

## Funcionalidades do Projeto
O projeto conta com as seguintes páginas e recursos:

- **Página inicial (`index.html`)**
  - Navbar fixa no topo
  - Hero section com imagem de destaque e chamada principal
  - Navegação por âncoras internas
  - Seção de artistas
  - Seção de playlists
  - Seção de conteúdos em alta
  - Layout moderno com foco em experiência visual

- **Página de login (`login.html`)**
  - Área de acesso do usuário
  - Formulário com campos de preenchimento
  - Botões estilizados
  - Estrutura visual integrada à identidade do projeto

- **Página de preços (`precos.html`)**
  - Exibição de planos ou opções de assinatura
  - Organização visual em blocos informativos
  - Layout pensado para fácil comparação

- **Recursos adicionais**
  - Navegação responsiva
  - Estilização personalizada com Tailwind CSS
  - Organização de arquivos em pastas separadas
  - Estrutura preparada para expansão com JavaScript

## Responsividade

O projeto foi desenvolvido com preocupação responsiva, buscando adaptação para diferentes dispositivos:

* **Celular**
* **Tablet**
* **Desktop**

Foram utilizadas:

* classes utilitárias do Tailwind CSS
* grids e layouts com `flex`
* ajustes de espaçamento e proporção por breakpoint
* adaptação da navbar e das seções principais para múltiplos tamanhos de tela

---

## Identidade Visual

A identidade visual do projeto foi construída para reforçar a proposta moderna da plataforma **Melodia**, utilizando:

* tons escuros e quentes como base visual
* destaque em **vermelho/laranja**
* imagens relacionadas ao universo musical
* layout contemporâneo com foco em impacto visual
* organização pensada para transmitir dinamismo, entretenimento e imersão

Essa combinação busca transmitir uma estética forte, moderna e conectada ao universo da música digital.
